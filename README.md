# Performance report pages

Pages for QuizPack Compiler's candidate performance reports, served by GitHub Pages at
https://issamfrancis.github.io/qpc-reports/.

Every report carries a QR code at its top right. Scanning it opens its paper's page here,
`report-<version>.html`, which draws the candidate's report again (the same PDF they were given)
from what the code carries.

- **Nothing about any candidate is stored here.** Each page holds only what its paper fixes: the
  exam's title and wording, the classifications and the names of their areas, and the report code.
  A candidate's details travel in the QR code's link after the `#`, which a browser never sends to
  the site. The pages ask search engines not to index them.
- **Adding a paper's page:** in the console, *Exam setup → The candidate's report → Download the
  report page*; then here on GitHub, *Add file → Upload files*, drop the file and commit. It is
  online about a minute later.
- **Keep every page** for as long as its reports are in use. Each report opens only its own paper's
  page, which is named for its version.
